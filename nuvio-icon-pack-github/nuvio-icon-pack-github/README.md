# Nuvio GitHub Icon Pack

A GitHub-ready icon pack for a Netflix-style Nuvio layout.

## Structure

```txt
icons/
  categories/
  providers/
gifs/
  providers/
dist/
  nuvio-icon-pack.json
icon-pack.json
```

## Streaming GIFs

The files in `gifs/providers/` are placeholders. Replace them with authorized animated GIFs using the exact filenames below:

- `netflix.gif`
- `prime-video.gif`
- `max.gif`
- `disney-plus.gif`
- `hulu.gif`
- `apple-tv-plus.gif`
- `paramount-plus.gif`
- `peacock.gif`
- `shudder.gif`
- `crunchyroll.gif`
- `mgm-plus.gif`

## GitHub raw URL pattern

After uploading to GitHub, use:

```txt
https://raw.githubusercontent.com/<owner>/nuvio-icon-pack/main/icon-pack.json
```

For individual assets:

```txt
https://raw.githubusercontent.com/<owner>/nuvio-icon-pack/main/icons/providers/netflix.svg
https://raw.githubusercontent.com/<owner>/nuvio-icon-pack/main/gifs/providers/netflix.gif
```

## Notes

The JSON and generated SVG placeholders are safe to commit. Do not commit copyrighted brand GIFs unless you have permission or they are licensed for your use.
